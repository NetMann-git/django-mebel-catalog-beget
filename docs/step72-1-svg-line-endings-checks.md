# Шаг 72.1 — окончания строк SVG в собранной статике

Основа: установленный шаг 72. Исправление clean_legacy_static.
Допускается отличие LF/CRLF для перечисленных SVG при совпадении
нормализованного SHA256. Для видео и растровых картинок — точное совпадение.
Реально изменённый SVG блокирует удаление всех файлов до записи.
Резервная копия сохраняет исходные байты, включая CRLF.
Данные БД, media, миграции и состав очищаемых файлов не меняются.
3 теста очистки прошли: обычные файлы, конфликты, сохранение прочих файлов,
повторный запуск, CRLF SVG, запрет изменённого SVG и точная копия.
Установщик: проверены check/apply/rollback, конфликты, CRLF и ZIP.
Фактическое содержимое SVG пользователя не получено: причина LF/CRLF
воспроизведена локально. Если check снова сообщает отличие — остановиться.
