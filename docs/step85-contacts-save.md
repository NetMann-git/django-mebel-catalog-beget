# Шаг 85 — сохранение контактов мастерской

Устанавливается поверх шага 84. Если настройки контактов отсутствуют,
редактор открывает пустую форму с выключенной публикацией.
Запись создаётся после сохранения корректной формы. Чтобы показать контакты
на сайте, включите публикацию и сохраните форму. Существующие настройки
открываются со своими значениями. Миграций нет.

Прошли 18 Django-тестов контактов. Проверены пустая форма, ошибка ввода,
сохранение без публикации и показ контактов после её включения.
