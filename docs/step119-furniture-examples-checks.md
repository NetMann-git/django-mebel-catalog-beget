# Шаг 119 — дополнительные примеры кухонь и шкафов

Подборка: 14 кухонь, 5 шкафов, 1 гардеробная. Источники — «Мария» и «КРК Мебель». Новых моделей IKEA нет. У каждого примера цветная обложка и семь дополнительных изображений. Всего 160 локальных JPEG до 1600 пикселей по длинной стороне. URL источников и контрольные суммы сохранены в данных.

Производитель показывает в галереях ракурсы, детали и варианты модели. В проектах «КРК Мебель» показаны ракурсы одного реализованного проекта. Описания написаны для обсуждения индивидуального заказа. Примеры не включены в портфолио мастерской. Цены изготовления и универсальные размеры не выдуманы.

Команда `load_southern_examples --check` проверяет данные и выводит план без записи. `--apply` создаёт проверенную резервную копию БД в `patch-backups` и добавляет отсутствующие карточки. Совпадающие примеры пропускаются с сохранением ручных изменений; занятый URL или артикул останавливает импорт. Транзакция откатывает новые записи, а обработчик ошибки удаляет вновь записанные изображения. Механизм загрузки общий с предыдущей подборкой, с отдельным каталогом файлов и префиксом артикулов.

Проверено:

- Django system check, четыре теста предыдущей и новой подборок.
- Цветные обложки, восемь разных файлов в каждой карточке, семь записей галереи, отсутствие IKEA в новых данных.
- Сохранение старых записей и ручных изменений при повторе, очистка при ошибке записи галереи.
- На отдельной SQLite после миграций: импорт шага 118, затем 119. Итог 40 карточек, 140 новых записей галереи. Все 20 новых страниц и каталог возвращают HTTP 200; штатные варианты изображений создаются при открытии карточек.
- Автоматическая предимпортная копия SQLite проходит integrity_check и содержит 20 прежних примеров.
- Установщик: check/apply, побайтовое сравнение, rollback/check и повторная установка.

Миграций в шаге нет. Восстановление данных из предимпортной копии выполняется отдельно от отката файлов установщиком. Проверки импорта проведены на SQLite; механизм MySQL использует существующий модуль резервирования проекта.
