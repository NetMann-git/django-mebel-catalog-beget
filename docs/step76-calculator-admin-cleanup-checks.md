# Шаг 76 — убрать автомобильные калькуляторы из админки

Основа: установленный шаг 75. Миграций нет. Из apps/calculator/admin.py
удалены регистрации восьми старых моделей: CalculatorDefinition,
RateVersion, UtilizationRate, CurrencyRate, CustomsDutyRate,
CustomsClearanceFeeRate, CustomsAggregateRate и ExciseRate.

На главной /admin/ больше нет раздела «Калькуляторы» и старых ссылок.
/admin/calculator/ и прямые адреса списков/создания/изменения/удаления
этих моделей не предоставляют старые административные формы (404).
Это снятие с регистрации, а не удаление данных: приложения, модели,
миграции и существующие таблицы сохранены. Для будущих мебельных
калькуляторов пока нет фиктивных моделей или пустых форм. Их регистрация
позже снова создаст раздел «Калькуляторы» штатным способом Django.
Публичные калькуляторы и size-helper остаются отключены шагом 75.
Админка изделий и галерея продолжают работать.

Проверки: 14 Django-тестов прошли на SQLite — отсутствие группы и
регистраций, прямые GET/POST-адреса старых моделей, сохранение существующих
CalculatorDefinition/RateVersion, админка изделий/галерея и проверки
очистки каталога шага 75. makemigrations --check --dry-run: No changes detected.
Django system check и git diff --check — OK.
Установщик проверен: check/apply/rollback, конфликты до записи,
точное восстановление исходников, LF/CRLF и ZIP — OK.
Windows, браузер и MySQL/Beget не проверялись.

Установка требует перезапуска Django, чтобы заново собрать реестр админки.
Резервная копия БД не нужна: схема и данные не меняются. Копии исходников
сохраняются в patch-backups/step76-*/original. Откат возвращает старые
модели в админку после перезапуска, данные остаются на месте.
