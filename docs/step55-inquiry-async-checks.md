# Шаг 55 — защита формы заявки от запоздавших ответов

Основа: установленный шаг 54. Рабочая копия восстановлена из ранее выданных
патчей 53/54; её HEAD перед изменением d1701b6.
Исправлен существующий car_inquiry.js: закрытие окна инвалидирует старую
загрузку и отменяет GET, повторное открытие имеет свою версию запроса.
Запоздалый GET не заменяет форму и не фокусирует скрытое поле.
Запоздалый ответ POST (успех, валидация, ошибка сети) не меняет закрытое
или повторно открытое окно. Сам POST не отменяется: заявка уже могла
сохраниться. Прежний overflow страницы восстанавливается, фокус возвращается
к кнопке открытия. Формы, поля, маршруты, серверное сохранение, права,
уведомления, галерея, поиск, стили и DEBUG не меняются.
Миграции и копия БД не нужны: установка меняет только JavaScript и тесты.
