# Шаг 86 — необязательная ссылка на карту

Устанавливается поверх шага 85. Контакты можно сохранить и опубликовать
с пустым полем карты. Публичный блок выводит кнопку карты при наличии ссылки.
Для заполненного поля редактор кабинета проверяет HTTP или HTTPS.

Миграция home.0010 меняет обязательность поля в Django. На SQLite
sqlmigrate показывает no-op. Перед миграцией сохраните копию базы в patch-backups.
Прошли 19 Django-тестов контактов, включая публикацию без карты.
