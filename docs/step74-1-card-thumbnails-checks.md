# Шаг 74.1 — миниатюры карточек и полный охват редактора

Основа: установленный шаг 74. Миграций нет.
Для /catalog/ и #portfolio «Мебель из нашего каталога» основной src теперь
уменьшенный файл до 400×300. srcset содержит версии 1x (400×300) и 2x
(800×600). Обе версии — физические WebP-копии, не оригиналы.
Браузер выбирает плотность под экран. Размеры ограничены, маленькие
исходники не увеличиваются, исходные фото не меняются.

Таблица /catalog/manage/ уже использует до 224×168 (шаг 74),
обложка редактора до 224×168, фотографии галереи до 320×240.
Эти конкретные места добавлены в проверку реальных HTML-страниц.
Общая карточка применяется также в избранном, истории, поиске
и блоках рекомендаций — они получают те же src/srcset.

Дополнительно исправлен пропущенный Python-виджет ImagePreviewWidget
(используется в формах, в том числе логотипа бренда): вместо value.url
в img.src он получает миниатюру до 400×400 для блока максимум 200×200.
HTML виджета теперь собирается с экранированием URL через format_html.
Обычная ссылка поля на оригинал сохраняется для намеренного открытия.

Проверки: 36 Django-тестов прошли на SQLite: размеры/вес настоящих
миниатюр на исходниках 4000×3000, src/srcset карточек, /catalog/manage/,
редактор изделия (обложка и фото галереи), виджет предпросмотра,
сохранение исходных байтов, формы изделия, admin-галерея, бренды,
витрина и каталог. Установщик проверен: check/apply/rollback,
конфликты до записи, LF/CRLF, распаковка ZIP. git diff --check — OK.
Браузер/Network, Windows и MySQL/Beget не проверялись.
Автоматически созданные миниатюры остаются в MEDIA_ROOT при откате;
оригиналы не удаляются и не пересжимаются.
