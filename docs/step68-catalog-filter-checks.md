# Шаг 68 — исправить заголовок и раскрытие фильтра

Основа: установленный шаг 67. Причина наклона: старое правило
.fc-sidebar details[open] summary span применяло rotate(45deg) ко всем
span, включая новый fm-filter-title, в котором находятся текст и иконка.
Аналогично старый общий span-селектор менял шрифт самого заголовка.
Оба правила ограничены отдельным .fc-filter-toggle-icon — индикатором +.
Текст и SVG настроек больше не затрагиваются этими правилами.

HTML сохраняет open. В catalog.js убраны сворачивание на мобильной
ширине, принудительное закрытие после AJAX и переключение по resize.
Начальное состояние открыто на всех экранах. Можно свернуть вручную:
это состояние сохраняется при AJAX-фильтрации в текущем посещении.
Полная загрузка страницы снова открывает фильтр. Ошибки валидации
раскрывают его, чтобы пользователь видел поля с ошибками.

## Проверки
21 Django-тест: products.tests.test_catalog_panel,
test_furniture_catalog, test_catalog_ajax; home.test_interface_icons.
Проверены HTML и AJAX с open, отдельный класс индикатора, ограниченность
правила поворота, каталог, поиск/фильтры, доступные подписи, разметка.
4 Node.js-теста: открытие на телефоне/компьютере, открытый фильтр после
AJAX, сохранение ручного закрытия при AJAX/resize, раскрытие при ошибках.
На прежнем JavaScript 3 теста воспроизводят ошибку, на новом все 4 проходят.
Тесты Django используют изолированную SQLite. git diff --check — OK.
Установка и откат проверяются отдельно: check/apply/rollback, конфликты
до записи, нормализация CRLF при проверке, восстановление исходных байтов.
Полная браузерная проверка в этой среде недоступна; Windows и production
не проверялись. Причина наклона установлена по точному CSS-селектору,
браузерный скриншот исправления не заявляется.

## Установка и ручная проверка
Миграций и изменений БД нет. Копии исходников — patch-backups.
Открыть /catalog/ после Ctrl+F5. Заголовок должен стоять горизонтально,
фильтр открыт на компьютере и телефоне. Применить категорию — фильтр
не закрывается. Можно вручную свернуть/раскрыть. Поворачивается только +.
Production: обычный collectstatic с настройками prod и перезапуск.
