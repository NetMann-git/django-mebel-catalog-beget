# Шаг 09 — список управления изделиями

## Результат
Шаблон /catalog/manage/ переведён на существующий furniture_base LUSTRID.RU.
На компьютере — таблица, на ширине до 720px — карточки с теми же данными и ссылками.
Понятные текстовые действия: «Добавить изделие», «Редактировать», «На сайте»,
«Удалить». Название открывает редактор, поэтому не ведёт на публичную 404 для
неопубликованных изделий. Ссылка «На сайте» показывается только при is_active.
Отображаются полное название, фото/«Нет фото», артикул, фактическая цена с валютой,
категория и опубликованность. Наличие и опубликованность не смешиваются.
Добавлен сброс поиска; запрос кодируется urlencode в ссылках пагинации, чтобы
символы +, &, кавычки и другие символы оставались частью запроса.
Страница имеет noindex/nofollow, но защита доступа по-прежнему серверная.

Сохранены прежний view, роли manager/admin/superuser, поиск по названию/артикулу/
категории, порядок по -id, 20 записей на страницу и штатный Paginator.
Ссылка «Удалить» ведёт на существующую страницу подтверждения, GET не удаляет.
Все изменения относятся к списку; редакторы, галерея шага 07 и «Тип изделия»
не менялись. Главная панель менеджера и страница подтверждения удаления пока
сохраняют прежнее оформление. Модели, данные и права не меняются.
Миграции, импорт и резервная копия БД при установке не нужны.
Фото показываются по исходному URL, без перезаписи оригинала/генерации миниатюр.

## Установщик
На отдельной копии проверены --check без записи, --apply, --rollback,
побайтовое восстановление исходников и удаление новых файлов; конфликт исходников
и нового файла останавливает установку до записи. Откат после пользовательской
правки отказывается перезаписывать её. Проверены CRLF/LF, точное восстановление
CRLF и установка/откат из распакованного итогового ZIP.

## Ручная проверка
После установки откройте /catalog/manage/ и обновите Ctrl+F5. Проверьте свои
изделия, поиск по названию/артикулу/категории, переходы между страницами, сброс,
редактирование и «На сайте» для опубликованного изделия. У черновика публичной
ссылки быть не должно. На телефоне проверьте карточки и доступность действий.
Для проверки ссылки удаления достаточно открыть подтверждение и отменить:
подтверждать удаление существующего изделия для проверки не требуется.
