# Шаг 39 — допустимые статусы в форме консультанта

Основа: шаг 38 d5834cc. Исправлен select формы /account/consultant/:
пункт pending удалён из доступных действий, потому что существующий backend
его отклоняет. Для текущих pending/new показывается disabled-подсказка
«Выберите статус» с пустым value; select required не даёт отправить её.
Подтверждена/Завершена/Отменена остаются доступными. Для этих трёх текущих
состояний сохраняется выбранное значение. Текущий статус по-прежнему виден
в соседней колонке. Backend, роли, CSRF, модель, календарь и переходы
не менялись. Возможность вернуть запись в pending/new не добавлялась.

confirmed/completed/cancelled приняты существующим обработчиком. Пустое,
pending/new и выдуманное значение в ручном POST отклоняются без изменения.
Смежные тесты проверили CSRF и права. Django check и git diff --check прошли.
Установщик: check/apply/rollback, конфликты до записи, CRLF/LF, точное
восстановление и отказ отката при ручных правках. Распакованный ZIP установлен
и отменён на полной отдельной копии, Django check прошёл.
