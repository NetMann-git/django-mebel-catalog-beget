# Шаг 33 — единственная страница избранного

Основа: шаг 32, commit 48b87c7.
Ссылка «Избранные изделия» из кабинета ведёт прямо на /wishlist/.
Старый именованный URL users:favorites (/account/favorites/) сохранён
и возвращает 302 на wishlist:list. Для гостя используется штатный
сессионный список, для вошедшего пользователя — его сохранённые изделия.
Перенаправление не требует входа и не меняет данные.
Старый шаблон оставлен как неиспользуемый файл для безопасной установки;
отдельную страницу он больше не обслуживает.

apps.users.test_login_redirect, apps.wishlist: 23 теста прошли на отдельной

сессионные сохранения гостя, неизменность Favorite после перехода,
прямая ссылка кабинета, публикация/скрытие, счётчики, рекомендации,
CSRF, удаление/очистка только собственного списка и другие закрытые URL.
Django check и git diff --check прошли.
Установщик: check/apply/rollback, конфликты до записи, CRLF/LF,
точный откат, отказ отката после ручных правок, распакованный ZIP;
полная отдельная копия: установка, Django check, откат.

и нажать «Избранные изделия»: адрес должен быть /wishlist/.
Открыть /account/favorites/ напрямую — должен произойти переход туда же.
Повторить в гостевом окне с добавленным изделием: сохранение остаётся.
Добавление, удаление, очистка и оформление используют прежнюю страницу;
