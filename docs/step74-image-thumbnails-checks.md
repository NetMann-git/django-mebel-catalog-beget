# Шаг 74 — настоящие миниатюры изображений по сайту

Основа: установленный шаг 73.1. Миграций нет, исходные загрузки не меняются.
Вместо исходников в src малых блоков используются физически уменьшенные
файлы easy-thumbnails (уже установлен в проекте). Копии создаются при первом
просмотре и кешируются в MEDIA_ROOT. Оригиналы сохраняются без пересжатия.
Размеры в пикселях: таблица категорий до 192×128 для показа 96×64,
таблица изделий до 224×168, галерейные миниатюры до 160×120,
отзывы/редактор галереи до 320×240, логотип бренда до 240×180,
карточки до 800×600, категории главной до 640×580,
предпросмотр редактора до 960×720, основное фото изделия до 1200×1000.
Без увеличения маленьких исходников, без обрезки оригиналов; WebP quality 92.
Векторные SVG-логотипы не растрируются.

Проверены/обновлены категории, таблица изделий, карточки каталога
(включая поиск, избранное и рекомендации через общую карточку), сравнение,
страницы брендов, списки брендов и рекомендаций, витрина главной,
изображения отзывов, списки и редакторы клиентов/команды, галерея
личного кабинета и /admin/, фотографии ранее импортированных изделий.
Большие фото загружаются при открытии увеличенного просмотра/ссылки.
JavaScript галереи теперь различает thumb, preview и full: переключение
основного изображения не подставляет оригинал, маленькие картинки
внутри лайтбокса тоже остаются миниатюрами. Оригинал выбирается только
в большом просмотре. Для одной фотографии сохраняется тот же контракт.
Поисковые подсказки не возвращают оригинал при сбое миниатюры;
ключ кеша подсказок обновлён. Отсутствующий/повреждённый исходник даёт
маленькую нейтральную заглушку. Огромный исходник не используется как fallback.

Для шести стандартных категорий включены 18 готовых уменьшенных WebP.
10 фрагментов старого дизайн-макета сохранены отдельными маленькими WebP;
SVG больше не загружает целую картинку макета ради маленького фрагмента.
Имеющиеся адаптивные editorial-изображения hero, процесса, материалов
и внутренних страниц уже имеют srcset и уменьшенные версии; они сохранены.
Новые изображения не генерировались, использованы производные существующих.

Проверки: 78 Django-тестов прошли на SQLite. На реальных файлах 4000×3000
проверены физические размеры, уменьшение веса, повторное использование URL,
сохранение исходных байтов; в HTML проверены src миниатюр и оригинальные
href/data-full для увеличения. Проверены загрузки категории, витрина,
карточка изделия, каталог, поиск, бренды, категории, admin-галерея,
редакционные картинки и внутренние страницы.
Node: исполнение реальных скриптов галереи с DOM-стендом — одно/несколько
фото, переключение, открытие/закрытие, миниатюры отзывов; node --check — OK.
Аудит 44 img-элементов шаблонов не обнаружил src с прямыми .image.url/.logo.url.
Django check, makemigrations --check --dry-run и git diff --check — OK.
Установщик: check/apply/rollback, конфликт до записи, CRLF текста,
точные байты WebP, распаковка ZIP проверены. На полной копии проверены
страницы, создание миниатюр и откат кода с сохранением оригиналов.
Полноценный браузер/Network, Windows и MySQL/Beget здесь не проверялись.

Исходники и готовая статика сохраняются установщиком в patch-backups.
Копия базы для этой установки не нужна: схема/записи каталога не меняются,
создаются только обычные записи кеша easy-thumbnails при просмотре.
Не удаляйте MEDIA_ROOT: там оригиналы и автоматически созданные миниатюры.
На Beget после переноса исходников: collectstatic с серверными настройками
и штатный перезапуск приложения. Не используйте collectstatic --clear.
