## Браузер
Использованы записанные реальные HTML и JSON-ответы Django на отдельной SQLite
через локальный сервер ответов. Это не production и не полноценный Django-сервер
в браузере. Реальные операции с сессиями и CSRF проверены автотестами.
Десктоп: список пяти изделий в обратном порядке реальных тестовых просмотров,
мебельные карточки и рекомендации. Мобильный iframe 390px (375px область
содержимого): заполненный список, кнопка очистки, счётчик 0, пустое состояние
и обновление страницы. scrollWidth=clientWidth=375 до/после очистки.
Тестовые карточки без фотографий показывают «Фото пока нет». Случайные
изображения не добавлялись, исходные URL фото проверены автотестами.
