# Шаг 22 — XML-карта мебельного сайта

Основа: dev_gpt c4e60a4, после шага 21.
Добавлены /sitemap.xml (индекс), /sitemap-pages.xml (главная и каталог),
/sitemap-products.xml (только is_active=True), /sitemap-brands.xml
(все существующие публичные страницы брендов, включая пустые).
Публичность соответствует существующим product_detail и brand_detail.
Адреса получаются через reverse и get_absolute_url, без изменения URL.
Категории с query-параметрами, поиск, формы, личный кабинет, управление,
избранное, сравнение и автомобильные калькуляторы в карту не включаются.

Использован встроенный django.contrib.sitemaps. Не добавляется Sites,
таблицы и модели не меняются. Домен и схема берутся из текущего запроса,
без использования старого SITE_URL. В локальной среде адреса локальные.
На каждом XML-листе не более 1000 ссылок, индекс перечисляет продолжение.
Нет вымышленных lastmod или changefreq; кеширование не добавлено:
снятое с публикации изделие исчезает из следующего ответа карты.
