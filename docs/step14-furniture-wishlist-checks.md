# Шаг 14 — избранная мебель: проверки

Основа: dev_gpt, 40c402a44f28b44c0dcdd211c06a0b0fc8cef6b7 (шаг 13).
Дата: 2026-11-03. Область: /wishlist/, единый счётчик избранного,
отображение только опубликованных изделий. Существующие URL и JSON-ключи
сохранены, используются готовая мебельная карточка и прежний wishlist.js.
Новые записи и фотографии установщиком не создаются.

## Исправленная ошибка
Ранее вошедшему пользователю избранное показывало снятые с публикации изделия.
Теперь страница, рекомендации и счётчик не раскрывают их названия/URL.
Сами Favorite и ID в сессии не удаляются при GET: повторная публикация
возвращает изделие в список. Счётчики страницы, каталога и ответов toggle
считают опубликованные изделия. Явная очистка пользователем работает как прежде.
Прямой вход на /wishlist/ выдаёт CSRF cookie для AJAX-действий.

## Браузер
Проверены реальные записанные HTML и JSON ответы Django с отдельной тестовой
SQLite через локальный сервер ответов. Это не браузерная проверка production
и не полноценный запущенный Django-сервер.
Десктоп: список, рекомендации, добавление из рекомендаций, удаление,
очистка, счётчик, пустое состояние и обновление страницы.
Мобильный iframe 390px (375px доступная область): пустой/заполненный список,
добавление и удаление последней карточки, счётчик, кнопки. Измерено:
scrollWidth=clientWidth=375, горизонтального переполнения нет.
Реальные записи/доступ/CSRF — автотесты на отдельной SQLite.
В браузерных тестовых карточках фото отсутствуют намеренно; отображается
«Фото пока нет». Чужие/случайные фотографии не добавлялись.

## Ограничения и ручная проверка
Windows/Python 3.11, MySQL/Beget и production непосредственно не проверялись.
После установки Ctrl+F5. Сохранить тестовое изделие из каталога, открыть
/wishlist/, проверить фото, валюту, удаление и счётчик; повторить после входа.
Проверить мобильный вид на реальном телефоне. Не очищать рабочее избранное
ради проверки: используйте отдельную гостевую сессию/тестовый аккаунт.
Миграции, импорт и резервная копия БД не нужны: установка меняет только код.
Резервные копии исходников создаёт установщик в patch-backups/step14-*.
Откат кода не отменяет действия пользователя с избранным после установки.
