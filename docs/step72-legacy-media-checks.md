# Шаг 72 — очистка автомобильных медиа

Основа: установленный шаг 71. Удалены 32 старых медиафайла (7 756 169 байт):
автомобильные видео MP4/WebM, постер, машины, автовоз, детали автомобиля,
старые логотипы, портреты прежней команды и декоративная стрелка.
Удалены 11 неиспользуемых шаблонов и CSS со ссылками на эти файлы.
В списке команды отключён fallback на старые статические портреты.
Загруженные фотографии сотрудников, изделий и мебельные изображения сохраняются.
Исторические миграции не меняются. Данные БД и media не удаляются.
Миграций нет. Перечень медиа с SHA256: docs/step72-legacy-media.json.

Команда clean_legacy_static --check/--apply удаляет только совпавшие по SHA256
копии перечисленных медиа из STATIC_ROOT. До удаления сохраняет все копии
в patch-backups/step72-collected-*/home/... . При отличающемся файле
останавливается до удаления. Повторное применение допустимо.
Исходники удаляет установщик с резервной копией и возможностью отката.
Для восстановления собранной статики после отката выполните collectstatic.
Хешированные варианты файлов manifest-хранилищ и CDN-кэш не очищаются;
нестандартные файлы вне репозитория автоматически не удаляются.

Проверки: 31 Django-тест прошёл. Тесты очистки (dry run, backup, конфликт, повторный запуск,
сохранение мебельного файла), брендинг, каталог и внутренние страницы.
Установщик проверен: check/apply/rollback, конфликты до записи,
точное восстановление бинарных файлов, CRLF только текстовых файлов,
установка и откат из ZIP. git diff --check пройден.
В оставшихся рабочих шаблонах/CSS нет ссылок на удалённые медиа.
Браузер, MySQL/Beget и реальная серверная статика не проверялись.
