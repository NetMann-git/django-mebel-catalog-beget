## Ручная проверка и ограничения
После установки Ctrl+F5. Выбрать 2–4 изделия в каталоге, открыть сравнение;
проверить реальные фото, цены/валюты, наличие и значения характеристик,
порядок колонок. На телефоне прокрутить таблицу, удалить одну и последнюю
позицию, добавить из рекомендаций. Проверку выполнять в отдельной тестовой
сессии, чтобы сохранить рабочую подборку.
Windows/Python 3.11, MySQL/Beget и production непосредственно не проверялись.
Миграции, импорт и резервная копия БД не требуются: установка меняет только код.
