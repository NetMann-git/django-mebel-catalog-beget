# Шаг 44 — исправить скрытие опубликованных контактов

Основа: шаг 43 171afcd. Удалён добавленный в шаге 43 фильтр содержимого,
который скрывал номера, адрес и соцсети при совпадении со значениями
home.0008_seed_contacts. Фильтр мог убрать весь блок при включённой
публикации; это лишнее правило, не согласованное с редактором контактов.

содержимого. Действительные контакты пользователь определяет в существующем
редакторе. Проверка is_published, экранирование, нормализация tel,
безопасные http/https URL и кеширование в пределах request сохранены.
Также карта как единственное заполненное поле больше не скрывает весь блок.
Шаблоны/расположение не менялись: телефон в шапке, полные данные в подвале.

проверьте их актуальность для мастерской в редакторе.
