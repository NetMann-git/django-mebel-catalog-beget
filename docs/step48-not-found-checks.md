диагностику Django — это нормально. Не отключайте DEBUG ради этого патча.

Локально можно проверить его тестами, не меняя рабочие настройки:
python manage.py test apps.home.test_furniture_not_found --settings=config.settings.dev --noinput
Тестовая БД временная, существующая БД не меняется.
В среде с DEBUG=False откройте несуществующий адрес и проверьте оба возврата.
