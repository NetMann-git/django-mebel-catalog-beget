# Шаг 32 — избранное в кабинете

Основа: шаг 31, commit b708a4f, ветка dev_gpt.
/account/favorites/ использует существующий WishlistView и мебельный шаблон
/wishlist/. Сохранены URL, вход для кабинета, карточки, рекомендации,
AJAX-добавление/удаление и очистка. Счётчик кабинета учитывает опубликованные
изделия. Снятие с публикации скрывает изделие без удаления Favorite;
повторная публикация возвращает его. Обычная очистка пользователем, как
и раньше, удаляет все его сохранения, включая скрытые.
JavaScript определяет страницу по существующим DOM-элементам вместо URL.
Модели, миграции, галерея и AJAX-поиск не изменены.
