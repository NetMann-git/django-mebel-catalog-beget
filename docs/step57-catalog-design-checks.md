# Шаг 57 — обновить дизайн каталога мебели

Назначение: привести /catalog/ к спокойной бежевой палитре главной.
Новый вводный блок, витрина без тяжёлых рамок, фотографии 4:3,
3 колонки на широком экране, 2 на планшете, 1 на телефоне.
Увеличены области нажатия кнопок карточек и полей фильтра.
Новый CSS ограничен .fc-catalog и подключён только в catalog.html.
Общие шаблоны карточек и JavaScript не изменяются. Фотографии берутся
из прежних product.image.url; новые медиа и данные не добавляются.
Размер файла и качество оригиналов не меняются, показ использует object-fit.
Шаг 56 необязателен: патч не меняет его файлы и совместим с шагами 55 и 56.
