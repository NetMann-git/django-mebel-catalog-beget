## Ручная проверка и ограничения
Открыть /account/password-reset/, проверить невалидный email.
Для полного сценария использовать отдельную тестовую учётку с email.
В стандартных dev-настройках письмо печатается в консоли runserver.
Перейти по ссылке, проверить ошибку несовпадения, сохранить новый пароль,
войти им и убедиться, что прежняя ссылка больше не даёт форму сброса.
Проверить отображение на телефоне. Не присылать пароль или ссылку сброса.
Windows, реальный телефон, доставка SMTP, MySQL/Beget и production
непосредственно не проверялись. Миграции и копия БД для установки
не нужны: меняются шаблоны, стиль, тест и отчёт. Копии исходников:
patch-backups/step28-*/original. Откат кода не откатывает пароли,
которые пользователь изменил через сайт. Push/публикации не было.
