# Шаг 121 — карточки выполненных проектов

Продолжение плана после направления «Кухни на заказ». Новых дублирующих URL проектов нет: сохраняются существующие адреса изделий, галерея, отзывы, миниатюры и связь заявки с изделием.

Для отмеченных выполненных работ добавлен блок «Проект в деталях»: задача клиента, решение мастерской, размеры, материалы и фурнитура. Состав цены берётся из существующего price_details, фотографии — из существующей галереи. В публичной карточке основная кнопка — «Рассчитать похожее», стоимость обозначена ориентиром проекта. В портфолио задача клиента показывается кратко, с переходом к работе. Картинки портфолио используют варианты card_small/card с srcset, без загрузки оригинала в миниатюру.

В кабинете новые поля сгруппированы в «Выполненный проект»; сверху есть ссылка к блоку. В Django Admin — отдельная группа после описания. Предпросмотр показывает сохранённый рассказ о работе. Новые поля необязательны; старые работы без них открываются с прежним описанием и характеристиками. У обычных изделий сведения проекта не выводятся. Опубликованные работы отбираются прежними правилами: активность, отметка портфолио и фотография. Примеры других производителей автоматически работами мастерской не становятся.

Подпись под основной фотографией проекта показывает существующий alt галереи и обновляется при переключении кадра. Галерея и её порядок сохраняются прежним механизмом.

Миграция products.0012_product_project_story добавляет четыре текстовых поля. Перед миграцией выполнить:

`python manage.py backup_before_projects --settings=config.settings.dev`

Команда создаёт проверенную копию SQLite/MySQL в BASE_DIR/patch-backups через существующий database_backup. Ошибка резервирования завершает команду с ошибкой; при ней миграцию не запускайте. Затем выполняется migrate. Для Beget используйте настройки сервера.

Проверки:

- 27 тестов: история проекта, реальный редактор кабинета, форма Admin, предпросмотр, экранирование HTML, ограничения длины, скрытые и обычные изделия, старые работы, галерея, портфолио, мебельные формы и заявка похожего проекта.
- Django system check без ошибок; makemigrations products --check --dry-run не находит расхождений.
- На копии базы шага 120 до миграции создана и проверена резервная копия. Миграция выполнена. Все 20 изделий, описания, цены, пути фото и отметки портфолио совпадают с исходными; новые поля пусты. Integrity_check резервной SQLite — ok.
- Установщик check/apply/rollback и контрольные суммы ZIP проверены отдельно, включая окончания строк Windows.

Браузерная визуальная проверка в рабочей среде недоступна. MySQL-миграция здесь не запускалась; резервирование использует штатную реализацию проекта.

Откат файлов установщика не восстанавливает БД. После ввода историй обратная миграция удаляет эти поля и их содержимое, поэтому не выполняйте её без свежей резервной копии. Сам установщик БД не меняет.
