# Шаг 05 — мебельный интерфейс каталога

Основа: шаг 04, коммит 0bc7285. Данные и модели не меняются, миграций нет.
Каталог /catalog/ и его GET-параметры сохранены. Использованы существующие
CatalogFilter, CatalogPaginator, CatalogRepository и AJAX-обработчик.

Изменения:
- мебельная шапка, подвал и метаданные вместо автомобильных;
- поиск, категория, диапазон цены в рублях, сортировка;
- карточка: название, категория, исходное фото, цена с фактической валютой,
  наличие, бейджи, избранное и сравнение;
- автомобильные характеристики не выводятся в карточке списка;
- для отсутствующего фото — явная заглушка, без случайной подмены;
- пустой список с предложением обсудить индивидуальный проект;
- мобильная панель фильтра и одна колонка карточек;
- JS не требует селектов марки/модели и сохраняет обработку старых параметров;
- при прямом открытии каталога выдаётся CSRF-cookie для POST избранного/сравнения;
- якоря шапки/подвала каталога ведут на соответствующие разделы главной;
- главная сохраняет прежние локальные якоря и внешний вид.
Фотографии не конвертируются: используется product.image.url с loading=lazy.
Новые модели, товары, категории, цены и фотографии в пользовательскую БД не добавляются.

Автоматические проверки на Linux / Python 3.12 / Django 5.2.8:
25 тестов — OK:
  apps.products.tests.test_furniture_catalog (7 новых тестов);
  apps.products.tests.test_catalog_ajax;
  apps.products.tests.test_filters;
  apps.products.tests.test_views.CatalogViewTest.
Проверены совместные фильтры, поиск кириллицей, сортировка, пагинация, сохранение
старых GET-параметров, HTML-часть замены, JSON подгрузки, отсутствие неактивных
товаров в обоих AJAX-режимах, CSRF, POST избранного/сравнения, экранирование поиска,
исходная ссылка фотографии и валюта USD, отсутствие автомобильного CSS/логотипа.
node --check catalog.js — успешно. Django check — no issues.
Установщик: --check без записи, --apply, --rollback, восстановление исходных байтов,
удаление новых файлов, отказ при конфликте, совместимость CRLF/LF — успешно.

Браузер Chrome:
- широкий viewport 1348 px: каталог с карточками, поиск «кухня» (6→3),
  сортировка цены по убыванию (180000→130000→80000), сброс;
- AJAX-подгрузка: 4→6 карточек без дублей;
- пустой каталог и кнопка перехода к обсуждению проекта;
- iframe шириной 390 px (375 px содержимого со скроллбаром): адаптивный вид,
  открытие панели фильтра, выбор «Шкафы» (6→3), закрытие панели после применения;
- нет горизонтального переполнения на узком экране.
Браузерный стенд возвращал сохранённые ответы реального Django test client
на временных демонстрационных данных; он не подключался к production/пользовательской БД.
Реальные серверные действия проверены отдельно Django-тестами. Демо-данные,
временные фото и сервер предпросмотра в патч не включены.

Ограничения:
- Windows Python 3.11, Beget/MySQL и реальный телефон в этом шаге не проверялись;
- детальная страница изделия, редактор, избранное, сравнение и история пока могут
  сохранять автомобильное оформление. Их URL и обработчики не изменены;
- фотографии пользователя и полнота реального каталога недоступны для проверки;
- для отсутствующих товаров не создаются вымышленные карточки;
- старые URL-фильтры учитываются и сохраняются, хотя автомобильных полей в новом
  фильтре нет. Их можно снять чипом «Дополнительные условия» или общим сбросом.

Ручная проверка: Ctrl+F5, все шесть категорий с главной, поиск, пустой результат,
мобильный фильтр, избранное/сравнение/подгрузка при наличии опубликованных изделий.
