# Шаг 06 — страница мебельного изделия

Основа: шаг 05, коммит ee01106. Новых моделей, миграций и операций изменения
существующих данных нет. Сохранены URL товара, car-inquiry и исходные идентификаторы.

Изменено:
- страница изделия наследует мебельную шапку, подвал и оформление;
- описание, категория, артикул, бренд, цена с валютой и наличие берутся из старых полей;
- сохранены meta_title/meta_description, характеристики и выбранная активная комплектация;
- галерея использует исходные файлы без thumbnail, crop или сжатия;
- при отсутствии обложки первым показывается фото из галереи;
- повторяющиеся имена файлов не увеличивают счётчик;
- кнопки миниатюр и увеличения работают с клавиатуры; Escape возвращает фокус;
- при закрытии увеличенного просмотра главное фото и счётчик синхронизируются;
- стрелки галереи не мешают вводу в поля формы;
- сохранены отзывы, фильтры, форма добавления, голоса и просмотр фото отзывов;
- недавно просмотренные и другие изделия используют мебельные карточки;
- сохранены избранное и сравнение;
- оба вида заявки оформлены под мебель, включая самостоятельную страницу без JS;
- поля, валидация, CSRF, honeypot, связь с изделием и source в БД сохранены;
- формулировки email/Telegram/MAX для заявки по изделию изменены на мебельные;
- поле города сохранено обязательным, как было, изменена только подпись;
- блок подключения старого CSS карточек сделан переопределяемым: мебельные
  страницы его отключают, остальные страницы сохраняют прежнее поведение.

характеристики, комплектация, отсутствие скрытых товаров/отзывов/опций,

проверены отдельно Django-тестами. Реальная доставка сообщений, Windows Python 3.11,
Beget/MySQL и физический телефон в этом шаге не проверялись.

Тестовые товары, отзывы, фото и сервер предпросмотра в ZIP не включены.

пути media не проверяется на каждом публичном запросе; корректность медиа пользователя
нужно проверить при наполнении. При полностью пустых полях фото показана явная заглушка.
Внутренние имена car_inquiry, car_order_success и поля источника оставлены ради совместимости.
Редактор и самостоятельные страницы сравнения/избранного/истории ещё могут сохранять
старую терминологию и оформление; в этот шаг они не входят.
