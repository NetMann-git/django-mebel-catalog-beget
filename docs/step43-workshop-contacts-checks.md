не создают пустых ссылок. Телефоны используют tel: с нормализованными цифрами.

В home.0008_seed_contacts обнаружены автотелефоны, адрес и соцсети.
Известные значения этой миграции исключаются на выводе по каждому полю,
без исправления или удаления БД. Для сравнения телефонов форматирование
игнорируется, российский начальный 8 для 11 цифр сравнивается с 7.

Это не произвольное распознавание автоконтактов: фильтр содержит конкретные
старые значения. Остальные опубликованные данные считаются данными редактора.

нужно отдельно согласовать его вывод: сам патч такой связи не предполагает.
