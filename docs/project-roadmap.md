# Согласованный порядок крупных задач LUSTRID.RU

1. Полноценные страницы направлений. Шаг 120 — кухни на заказ. Шкафы, гардеробные и стеллажи остаются следующими направлениями для использования проверенного подхода.
2. Карточки выполненных проектов. Шаг 121 — задача, решение, размеры, материалы; существующие состав цены, галерея и заявка похожего проекта.
3. Единая заявка на расчёт. Шаг 122 — общие поля, обработчик и защищённые вложения для направлений, изделий и проектов; самостоятельная страница /request/. Старые адреса сохранены.
4. Учёт заказов — следующая крупная задача.
5. Управление содержимым сайта.
6. Сквозная проверка перед запуском.

Отмеченные шаги означают реализованные возможности в коде. Установка патчей на компьютере и сервере пользователя подтверждается его результатами команд. Реальные истории выполненных работ заполняются мастерской; вымышленные сведения о заказчиках и проектах не добавляются.
