## Результат
/account/manager/ оформлена в стиле LUSTRID.RU, с адаптацией к узкому экрану.
Основная сводка: все изделия, опубликованные, неопубликованные, новые обращения.
Данные получаются из Product и CallbackRequest двумя агрегирующими запросами.
Карточка новых обращений ведёт на существующий фильтр ?status=new.
Рабочие ссылки: изделия, обращения, категории, характеристики, бренды, рекомендации.
Сводка обращений отдельно показывает new/processed/cancelled; отзывы показывают
прежнюю статистику, при отсутствии оценок отображается прочерк.

Старые расчёты Appointment, периоды и статистика отзывов не переписаны.
Статистика записей, изделий в записях и пользователей сохранена в раскрываемом
блоке. Точное название «Записи по пользователям» соответствует прежнему запросу
по Appointment.user; это не рейтинг сотрудников. Обращения с форм сайта и записи
Appointment не смешиваются. Ссылки «Наши клиенты», «Импорт из Encar» и «Модели
автомобилей» сохранены в дополнительных инструментах. Их URL и доступ не удалены.

## Доступ
Сохранён login_required с возвратом next после входа и используется существующий
role_required(ROLE_MANAGER, ROLE_ADMIN). Для обычных
пользователей роли не расширены: клиент, консультант и staff без нужной роли
не получают статистику. Отсутствующий профиль обработан без ошибки 500.
Исправлен обнаруженный отказ суперпользователю с ролью customer: общий декоратор
уже предусматривает доступ суперпользователя ко всем служебным разделам.
В личном кабинете ссылка на панель теперь также видна суперпользователю.
Роли/профили в БД не изменяются. Перед запросами статистики проверяется доступ.
Личные данные обращений (телефон, комментарий, имя) в сводку не выводятся.

Модели и данные не меняются. Миграции, резервная копия БД, импорт и перенос медиа
не нужны. «Тип изделия», редакторы и галерея остаются без изменений.

## Ручная проверка
Войдите менеджером/администратором либо суперпользователем. В личном кабинете
откройте «Панель менеджера», обновите Ctrl+F5. Сверьте количество изделий и новых
обращений с соответствующими списками, проверьте рабочие ссылки и раскрытие
«Статистика записей»/«Дополнительные инструменты». На телефоне проверьте ширину
и читаемость. При нулевых данных все счётчики должны быть нулевыми.
