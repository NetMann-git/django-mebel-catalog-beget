# Шаг 19 — публичная страница бренда

Основа: dev_gpt, 343f227 (шаг 18), дерево совпало с выданным шагом 18.
Дата: 2026-11-03. Страница /catalog/brand/<slug>/ переведена на мебельную
оболочку и готовые карточки каталога. Сохранены адрес, бренд, описание,
страна, логотип, SEO-поля, репозиторий и выборка только опубликованных изделий.
Модели и данные не меняются. Фото/логотип выводятся через исходные URL.

Прямой GET выдаёт CSRF cookie для кнопок избранного/сравнения; карточки
получают текущее избранное гостя/аккаунта. Title использует прежнее seo_title.
Метаописание берётся из meta_description, даже если текст описания пустой;
при отсутствии используется краткий текст описания. Добавлены мебельные
Open Graph поля без старого автомобильного описания.

## Браузер
Использованы реальные записанные HTML/JSON-ответы Django с отдельной SQLite
через локальный сервер ответов. Это не production и не полноценный Django
в браузере. Реальные сессии/CSRF/изоляция данных проверены автотестами.
Десктоп: описание, страна, число изделий, мебельные карточки, добавление
в избранное и сравнение, обновление страницы с сохранённым состоянием.
Мобильный iframe 390px (375px область содержимого): заполненная страница,
удаление из избранного/сравнения и пустой бренд. scrollWidth=clientWidth=375.
В браузерных данных фото и логотипы отсутствовали намеренно; случайные
изображения не добавлялись. Исходные URL медиа проверены автотестами.

## Установщик и ручная проверка
На отдельной копии: check без записи, apply/rollback с восстановлением байтов,
конфликты старого/нового файла до записи, CRLF/LF, отказ отката после
пользовательских изменений, установка/откат из распакованного финального ZIP.
После установки Ctrl+F5. Из панели «Бренды» открыть «Страница бренда» или
нажать бренд в карточке изделия. Проверить собственные логотип, описание,
фото, цены/валюты, кнопки избранного/сравнения и телефон. Для пустого состояния
использовать тестовый бренд; не снимать реальные изделия с публикации ради теста.
