# Шаг 71 — поиск и страницы обращений

Основа: шаг 70. Миграций нет.

Добавлены поиск по имени, телефону, email, городу, изделию и комментарию,
страницы по 20 обращений и стабильный порядок от новых к старым.
Телефон ищется без разделителей. Запрос ограничен 200 символами;
символы регулярных выражений воспринимаются буквально.
Смена статуса сохраняет поиск, статус фильтра и страницу.
Перенаправление допускает только внутренний адрес списка.
Счётчики всех и новых обращений остаются общими.

Проверки: 21 Django-тест прошёл (6 новых и 15 существующих).
Проверены кириллица, регистр, телефон, буквальные спецсимволы,
пагинация, доступ менеджера, запрет доступа клиента, экранирование,
сохранение параметров и отсутствие изменений данных при поиске.
Установщик: check/apply/rollback, конфликты без частичной записи,
CRLF и установка из распакованного ZIP проверены.

Ограничения: тесты выполнены на SQLite; MySQL и визуальная проверка
в браузере не выполнялись. Реальная отправка уведомлений не проверялась.
После установки откройте /appointments/callbacks/ под менеджером,
найдите телефон без разделителей и смените статус найденной заявки.
