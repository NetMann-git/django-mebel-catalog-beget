# Шаг 62 — сравнение и пояснения действий

Основа: шаг 61 (b2ce655). Общий шаблон кнопки сравнения используется в
каталоге, AJAX-выдаче и карточке изделия. Постоянная SVG-иконка, подписи
«Добавить к сравнению» / «Убрать из сравнения», aria-pressed и название
изделия в доступном имени. JavaScript меняет только подпись, сохраняя SVG.
Текст пустого сравнения приведён к новой подписи.

Общие CSS/JS подключены в base.html: пояснения для ссылок, кнопок, summary
и submit/button inputs на страницах сайта, использующих этот шаблон.
Django admin использует собственный шаблон и этим патчем не меняется.
Основные действия имеют развёрнутые пояснения: сравнение, избранное,
галерея, заявка, фильтры, разделы, контакты, личный кабинет.
Для прочих действий используется существующий title или пояснение по
названию/адресу. Можно уточнить текст через data-help на элементе.
Это не ручные уникальные тексты для каждой произвольной ссылки из контента.

Пояснение открывается наведением через 350 мс или клавиатурным фокусом.
Escape закрывает; aria-describedby сохраняет существующие идентификаторы.
Текст вставляется через textContent; состояния сравнения/избранного
обновляют уже открытое пояснение. Работает с AJAX-элементами.
На сенсорном экране обычное касание выполняет действие без всплывающего
перекрытия: hover-подсказки не показываются, подписи сравнения полные.

## Ручная проверка
После Ctrl+F5 открыть каталог и изделие. Проверить SVG, добавление и
удаление из сравнения, счётчик, переход «К сравнению», AJAX-фильтрацию.
Навести на меню, кнопки заявки, избранного, фотографии, ссылки подвала;
проверить пояснения и Escape. Повторить с Tab. На телефоне проверить,
что длинная подпись помещается и обычное касание выполняет действие.
