# Шаг 84 — ссылки мастерской в публичных контактах

Основа — шаг 83. Общий блок контактов пропускает известные адреса
автомобильных каналов Telegram, ВКонтакте и MAX, включая варианты с
параметрами ссылки и завершающим слешем. Собственные ссылки мастерской,
телефоны, адрес и карта выводятся по прежним правилам публикации.
Редактор показывает пояснение. При создании отсутствующей настройки
редактор больше не заполняет поля соцсетей автомобильными адресами.
Существующие записи доступны для редактирования. Миграций нет.

Прошли 17 Django-тестов контактов. Проверены главная, каталог, страница
контактов, сохранение адресов и показ ссылок мастерской. Проверка
в браузере и на хостинге не выполнялась.
